## Description

Small RimWorld mods that each change a few numbers and leave everything else alone. Every mod has its own folder, readme and changelog.

* [Bye Loved One](./bye-loved-one) - makes the "loved one sold" thought bearable. [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3650162799)
* [Lighter Chunks](./lighter-chunks) - stone chunks weigh a fifth of what they used to. [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3650156682)
* [Power Poles Extended - Rebalance](./power-poles-electricity-rebalance) - the lamp poles from Power Poles Extended use 30 W instead of 100 W. [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3650142147)

## Installation

Subscribe on the Steam Workshop. To install by hand instead, copy a mod's `Mod` folder into your RimWorld `Mods` folder and rename it after the mod, for example `bye-loved-one`.
