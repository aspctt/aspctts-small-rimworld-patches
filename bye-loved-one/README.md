## Description

Makes the "loved one sold" thought bearable. Colonists still mind when you sell someone they love, but they get over it in a quadrum instead of two years. Perfect for selling those babies that can barely hold a tool.

* **Mood** - -10 to -2
* **Opinion** - -10 to -2
* **Duration** - 120 days to 15 days
* **Stack limit** - 10 to 2

## Installation

Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3650162799), or copy the `Mod` folder from this mod's folder in the repository into your RimWorld `Mods` folder and rename it to `bye-loved-one`.

**REMOVE ANY OLD VERSIONS BEFORE INSTALLING**.

## Compatibility

No dependencies. Works with anything that doesn't change the same thought.
